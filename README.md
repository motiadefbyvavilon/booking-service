# РесурсТайм — сервис бронирования общих ресурсов

Фронтенд-приложение на **Vue 3 + Vite** для организации и управления бронированием
общих ресурсов компании (переговорные, оборудование, специалисты).

## Возможности

1. **Календарная форма бронирования**
   - Недельный календарь с расписанием занятости всех ресурсов.
   - Создание бронирования кликом по свободному слоту (дата, время, ресурс подставляются автоматически).
   - Фильтр календаря по конкретному ресурсу.

2. **Уведомления и синхронизация**
   - Автоматическое уведомление всех участников при создании, изменении и отмене бронирования
     (раздел «Уведомления» + всплывающие тосты, счётчик непрочитанных).
   - Экспорт бронирования в `.ics` для синхронизации с личным календарём пользователя.

3. **Предотвращение повторного бронирования**
   - Проверка пересечения времени по тому же ресурсу при создании и редактировании.
   - Понятное предупреждение со списком конфликтующих бронирований.

4. **Управление ресурсами**
   - Добавление, редактирование и удаление ресурсов (тип, вместимость, цвет метки).
   - Назначение ответственного лица за каждый ресурс.
   - Подтверждение удаления с учётом связанных бронирований.

Данные хранятся в `localStorage` браузера (демо-режим без бэкенда);
при первом запуске подставляются примеры ресурсов и бронирований текущей недели.

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Vue Router 4
- Pinia
- Без UI-библиотек: собственные компоненты и дизайн-токены (OKLCH)

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # продакшн-сборка в dist/
npm run preview  # просмотр продакшн-сборки
```

## Структура

```
src/
├── main.js
├── App.vue               # каркас: сайдбар, навигация, тосты
├── router/               # маршруты: Календарь / Ресурсы / Уведомления
├── stores/booking.js     # Pinia: ресурсы, бронирования, уведомления, конфликты
├── utils/datetime.js     # работа с датами, проверка пересечений
├── utils/ics.js          # генерация .ics для синхронизации с календарём
├── views/
│   ├── CalendarView.vue      # недельный календарь бронирований
│   ├── ResourcesView.vue     # CRUD ресурсов
│   └── NotificationsView.vue # лента уведомлений
└── components/
    ├── BookingModal.vue      # создание/редактирование бронирования, проверка конфликтов
    ├── ResourceModal.vue     # создание/редактирование ресурса
    └── ToastStack.vue        # всплывающие уведомления
```
